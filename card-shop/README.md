# Card Shop — generic vendor demo

Fictional brand for TCG vendor outreach. Separate copy of the DC storefront, with white/orange identity, WELCOME10 offer, own local cart/favourites storage and neutral community pictures. The highlights section links directly to the user-approved ShortPocketMonster YouTube channel. Decorative slogans, category icons, story popups and the fake pickup section were removed. Delivery, pickup and checkout are local demo interactions only.

Public URL: https://kites-studio.github.io/preview/card-shop/
