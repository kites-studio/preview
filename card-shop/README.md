# Card Shop — generic vendor demo

Fictional brand for TCG vendor outreach. Separate copy of the DC storefront, with forest/cream/lime identity, WELCOME10 offer, own local cart/favourites storage and neutral community pictures. Sample social-story cards link into the catalogue; there is no fabricated TikTok profile or playable video. Delivery, pickup and checkout are local demo interactions only.
