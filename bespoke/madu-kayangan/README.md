# Madu Kayangan client preview

Client link: https://kites-studio.github.io/preview/madu-kayangan/
Gallery: https://kites-studio.github.io/preview/all/

Static homepage, no build, login or ChatGPT dependency. Preserves Madu Kayangan branding, original package prices and public WhatsApp number. Basket, delivery form and order review run in the browser. WhatsApp opens a draft; no message or payment is automatically processed. The demo is noindex, nofollow. The product hero is AI concept imagery derived from the original bottle photo and labelled in the footer. Asset originals and provenance are stored at assets/madu-kayangan in the private source repository.

Publish from the private madebykites source with the existing kites-demos subtree workflow.
